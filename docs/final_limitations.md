## 1. Explicit Limitations

```
┌───────────────────────────────┬────────────────────────────────────────────────────────────────────────┐
│ Domain                        │ Explicit Boundary & Limitation Details                                 │
├───────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ 1. Demographic Baseline       │ Relies on Census of India 2011 (the latest published national census). │
│                               │ Represents a relative baseline; does not reflect 2026 live population. │
├───────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ 2. Health & Bed Capacity      │ Benchmarked to normative IPHS 2022 standards (1.0 bed/1,000 pop).      │
│                               │ Does not track real-time hospital occupancy during emergencies.        │
├───────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ 3. Cyclone Shelters           │ Reflects static NCRMP designated capacity for coastal mandals.         │
│                               │ Inland mandals use temporary institutional assets requiring audit.     │
├───────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ 4. Evacuation Road Access     │ Road density (km/km²) serves as an egress infrastructure proxy.        │
│                               │ Does not incorporate live GPS traffic or real-time debris blockages.   │
├───────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ 5. Safe Habitable Land        │ Defined as contiguous terrain with slope < 15° outside flood zones.    │
│                               │ Represents physical headroom, NOT legally acquired government land.    │
├───────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ 6. Flood Layer                │ JRC Global Surface Water (1984–2021) captures historical recurrence.   │
│                               │ It is a spatial exposure proxy, NOT a real-time hydrodynamic forecast. │
├───────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ 7. What-If Scenario Sliders   │ Scenario multipliers are mathematical sensitivity exploration tools.   │
│                               │ +30% hazard is NOT a claim of 30% more rainfall.                       │
├───────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ 8. Governance Mandate         │ Sahayata is an AI-assisted decision-support platform for authorities.  │
│                               │ It NEVER issues automated relocation orders or instructions to citizens│
└───────────────────────────────┴────────────────────────────────────────────────────────────────────────┘
```

---

## 2. The Credibility Principle

Disclosing these limitations strengthens administrative trust. Rather than overclaiming black-box predictive capabilities, Sahayata offers disaster management authorities an **auditable, reproducible, and transparent decision-support tool**.
